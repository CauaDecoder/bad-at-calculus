# Referências

Materiais de apoio que não são código nem documentação escrita.

Sugestão de organização:

```
references/
├─ math/     figuras e capturas de conceitos (ex.: tangente de x² e x³ — experiência alvo da v0.1)
├─ design/   direção de design da Vértice (README) + capturas/ (ignorada pelo git)
├─ ui/       capturas de telas de referência de design (ver ../04-design/referencias.md)
└─ papers/   artigos sobre algoritmos (parsing, amostragem adaptativa, derivação simbólica)
```

Use nomes descritivos em `kebab-case`: `tangente-x-quadrado.png`, `derivada-x-cubo.png`.
Respeite direitos autorais: guarde apenas material próprio, livre ou com permissão.
